# sort-files 스킬

어수선하게 쌓인 폴더를 깔끔하게 정리하는 스킬이다.
**파일 유형별 정리**와 **중복 폴더의 날짜별 병합**이 핵심 기능이다.

## 스크립트 위치

이 스킬 디렉토리의 `scripts/` 폴더에 두 가지 도구가 있다:
- `scan_folder.py` — 폴더 현황 스캔 및 중복 그룹 감지
- `organize_files.py` — 파일 이동 실행 (유형별 / 날짜별)

## 작업 흐름

### 1단계: 폴더 접근 권한 요청

폴더에 접근이 필요하면 `request_cowork_directory` 도구로 권한을 요청한다.
사용자가 폴더를 이미 연결했다면 바로 스캔한다.

### 2단계: 현황 스캔

```bash
python3 <skill_dir>/scripts/scan_folder.py "<target_folder>"
```

스캔 결과를 사용자에게 요약해서 보여준다:
- 파일 유형별 개수와 용량
- 중복/번호 붙은 폴더 그룹 감지 여부

### 3단계: 정리 방향 확인 (AskUserQuestion 사용)

스캔 결과를 바탕으로 **반드시 AskUserQuestion으로 확인**한다.

물어볼 내용:
1. **정리 방식**: 유형별(이미지/영상/문서 등) vs 날짜별 vs 중복만 제거 vs 현황 보고만
2. **중복 폴더 그룹이 있다면**: 날짜별로 묶을지 그대로 둘지

예시 질문:
```
어떤 방식으로 정리할까요?
- 파일 유형별 정리 (이미지/영상/문서 등 폴더로 분류)
- 날짜별 정리
- 중복 폴더만 합치기
- 현황 보고만 받기
```

### 4단계: 정리 실행

#### 파일 유형별 정리

```bash
python3 <skill_dir>/scripts/organize_files.py "<folder>" --by-type
```

생성되는 폴더 구조:
```
<폴더>/
├── 이미지/     (.png, .jpg, .heic, .webp 등)
├── 영상/       (.mp4, .mov 등)
├── 음악/       (.mp3, .wav, .m4a 등)
├── 문서/       (.pdf, .docx, .xlsx, .csv 등)
├── 디자인/     (.psd, .ai, .eps, 폰트 등)
├── 압축/       (.zip, .rar, .dmg 등)
├── 앱_설치파일/ (.pkg, .dmg, .exe 등)
├── 데이터/     (.json, .xml, .csv 등)
└── 코드/       (.py, .js, .ts 등)
```

기존 폴더들(프로젝트/업무 폴더 등)은 건드리지 않는다.
파일만 이동한다.

#### 중복 폴더를 날짜별로 병합

"이름 (1)", "이름 (2)", "이름 - 2025-10-01T..." 형태로 쌓인 폴더 그룹을 날짜별로 묶는다.

```bash
python3 <skill_dir>/scripts/organize_files.py "<folder>" \
  --by-date "원본 폴더 이름" \
  --output "정리된_폴더명"
```

결과 구조:
```
정리된_폴더명/
├── 2025-10-01/
│   ├── 이름 (1).zip
│   └── 이름 (2).zip
├── 2025-11-15/
│   └── 이름 - 2025-11-15T130000.000.zip
...
```

#### 두 작업 병행

중복 폴더 날짜 병합 → 파일 유형별 정리 순서로 진행한다.
중복 폴더를 먼저 정리해야 루트에 항목이 줄어 유형별 정리가 깔끔하다.

### 5단계: 결과 보고

정리 완료 후 사용자에게 요약:
- 이동된 파일 수와 폴더별 현황
- 절약된 루트 항목 수
- 남은 미분류 파일이 있다면 목록

## 주의사항

### macOS 파일 인코딩 (중요)

macOS(APFS/HFS+)는 파일명을 NFD 유니코드로 저장한다.
Python의 기본 문자열 비교(`startswith`, `==`)는 NFC 기준이라 NFD 파일명과 불일치할 수 있다.

**반드시 `unicodedata.normalize("NFC", name)` 또는 `"NFD"`로 정규화 후 비교한다.**

스크립트들은 이미 이를 처리하고 있다. 직접 Python 코드를 작성할 때는 아래를 참고:

```python
import unicodedata
name_nfc = unicodedata.normalize("NFC", item.name)
# 이제 name_nfc로 비교
```

### 파일 이름 충돌

같은 이름의 파일이 대상 폴더에 이미 있을 경우 `_1`, `_2` 식으로 자동 처리한다.
`safe_dest()` 함수가 `organize_files.py`에 구현되어 있다.

### 이모지/특수문자 파일명

이모지가 파일명 앞에 붙어 확장자 인식이 안 되는 경우가 있다.
`detect_ext()` 함수가 파일명 끝을 직접 검사해 보완한다.

### 삭제는 사용자 확인 후

파일/폴더 삭제는 반드시 사용자에게 구체적으로 무엇을 삭제할지 알리고 확인 후 진행한다.
`.crdownload` (미완료 다운로드), `.DS_Store` 같은 시스템 파일은 사용자에게 알린 후 삭제 제안한다.

4. 사용자 선택에 따라 정리 실행
